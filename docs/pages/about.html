About

This is what happens when a C programming project goes haywire, and ships a full Scrabble client anyway.

Overview

Scrabble.c is a cross-platform desktop build of the classic word game, written in C with raylib and RayGUI. Version 1.0.0-RC (closed beta) covers local turn-by-turn play, audio, settings, saves, wildcards, and luxury board tiles. Network play is underway.

More project notes live at sonothamin.dev/Scrabble.c. The author site is sonothamin.dev.
