Build from source

Raylib and Premake are vendored under build/. Short paths:

  • Linux — install X11/OpenGL/ALSA headers, run Premake, then make.
  • macOS — Xcode Command Line Tools, Premake via premake5.osx, then make.
  • Windows — w64devkit + build-MinGW-W64.bat, or the Visual Studio batch scripts.

Full setup notes are in DevEnvironment.md and the project README.

After install

Launch Scrabble, start a local game, and keep an eye on the hotkey bar. Mute and fullscreen are a keystroke away from the main menu.
